# Sabor Express

Aplicativo em Python para gerenciar restaurantes em um menu interativo no terminal.

## Funcionalidades

- Cadastrar novos restaurantes
- Listar restaurantes já cadastrados
- Alternar o status de um restaurante entre ativo e desativado
- Encerrar a aplicação

## Como executar

1. Abra o terminal no diretório do projeto.
2. Execute:

```bash
python app.py
```

## Menu principal

O programa oferece as seguintes opções:

1. Cadastrar restaurante
2. Listar restaurantes
3. Ativar restaurante
4. Sair

## Estrutura do projeto

- `app.py`: arquivo principal com a lógica da aplicação e menu interativo.

## Observação

Este projeto foi desenvolvido como exemplo de estudo para praticar estruturas básicas em Python, como listas, dicionários, funções e interação com o usuário via terminal.
